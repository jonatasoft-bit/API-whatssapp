1
Instalar os programas
Um script faz tudo automaticamente

No Mac, o instalador roda no Terminal. Siga os passos:

bash ~/Downloads/Kit-V30-Instalador/macos/instalar.sh
ℹ️ O instalador vai pedir sua senha de usuário (a mesma que você usa para ligar o Mac). É seguro — ela não é enviada a lugar nenhum.
✅ O que será instalado: Node.js, Python, Claude Desktop, Obsidian, WhatsApp, Docker, n8n e Claude Code (linha de comando).

No Windows, o instalador roda automaticamente. Siga os passos:

⚠️ O Windows pode mostrar um aviso de segurança. Clique em "Mais informações" e depois "Executar assim mesmo".
✅ O que será instalado: Node.js, Python, Claude Desktop, Obsidian, WhatsApp, Docker, n8n e Claude Code.
2
Abrir e configurar o Claude
Criar conta e fazer login

O Claude é o assistente de IA que vai controlar o kit. Você precisa criar uma conta gratuita.

💡 A conta gratuita tem créditos iniciais. Para uso intenso do kit, considere o plano Pro (US$ 20/mês) depois.
3
Criar sua Chave de API (Anthropic)
A "senha secreta" que conecta tudo

A chave de API é como uma senha que permite que o kit use o Claude de forma automática. Siga os passos:

⚠️ Não compartilhe essa chave com ninguém. Ela é como uma senha do banco. Se perder, gere uma nova no mesmo site.

Agora cole a chave no terminal/Claude quando pedida:

claude login

Cole a chave quando o terminal pedir e pressione Enter.

No Claude Desktop, nas configurações (ícone de engrenagem), procure "API Key" e cole a chave gerada.

4
Conectar o WhatsApp
Escanear QR Code com seu celular
📱 Você precisa do seu celular com WhatsApp nesta etapa. Deixe-o do lado.

O WhatsApp Desktop já foi instalado. Agora você precisa conectar sua conta:

💡 Se for uma conta nova do WhatsApp, crie pelo celular primeiro: baixe o app, insira seu número e siga o cadastro.
5
Fazer login no Facebook
Necessário para automações de Marketplace

O kit usa o Facebook para postar no Marketplace automaticamente. Você precisa fazer login no navegador deste computador.

⚠️ Contas novas podem ter limitações iniciais no Marketplace. Se acontecer, aguarde alguns dias antes de usar as automações de postagem.
💡 Mantenha o Facebook logado neste navegador. O kit vai usar essas credenciais para postar automaticamente.
6
Ativar o Kit no Claude
Um único comando configura tudo para seu negócio

Agora vamos rodar o wizard de instalação do kit. Ele vai adaptar tudo ao seu negócio automaticamente.

instalar kpa30
🧙 O wizard vai fazer perguntas sobre seu negócio (nome, nicho, produto, público, etc.) e configurar o kit para você. Leva cerca de 5 minutos.
