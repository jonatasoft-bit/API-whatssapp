# Kit Piloto Automático V30 — Instalador

Instala e configura automaticamente todas as ferramentas do Kit Piloto Automático V30.

## Programas instalados

| Ferramenta | Função |
|---|---|
| Node.js | Runtime JavaScript |
| Python 3 | Automações e scripts |
| Git | Controle de versão |
| Claude Code | Assistente de IA (CLI) |
| n8n | Automações avançadas |
| WhatsApp MCP | Integração WhatsApp com Claude |
| Composio MCP | Automações via API |
| Playwright MCP | Automação de browser |
| Sequential Thinking MCP | Raciocínio estruturado |

## Como instalar

### macOS
```bash
bash Kit-V30-Instalador/macos/instalar.sh
```

### Linux
```bash
bash Kit-V30-Instalador/linux/instalar.sh
```

### Windows
Clique com botão direito em `Kit-V30-Instalador/windows/instalar.bat` e escolha **"Executar como administrador"**.

## Após a instalação

1. Obtenha sua chave API em https://console.anthropic.com
2. No terminal, execute: `claude login`
3. No Claude, digite: `instalar kpa30`

## Comandos do dia a dia

| Comando | O que faz |
|---|---|
| `instalar kpa30` | Instala e configura o kit (1x por máquina) |
| `briefing` | Monta briefing de cliente ou projeto |
| `criar` | Gera conteúdo, copy, posts e materiais |
| `whatsapp` | Monta fluxos de WhatsApp |
| `automatizar` | Cria automação de processo |
