                         INSTALAÇÃO RÁPIDA
═════════════════════════════════════════════════════════════════════

PASSO 1: Baixar Arquivos
────────────────────────
✅ manutencao_impar_v2.py        (NOVO - usar este)
✅ MANUTENCAO_IMPAR_V2_MELHORIAS.md
✅ GUIA_RAPIDO_V2.txt            (este arquivo)

LOCAL: Mesma pasta (ex: C:\Downloads\Manutencao-v2)


PASSO 2: Opção A - Upgrade de v1.0
───────────────────────────────────
(Se já tem v1.0 instalado)

1. Abra PowerShell (admin)
2. Execute:
   schtasks /delete /tn "Ímpar_AutomationMonitor" /f
3. Aguarde confirmação


PASSO 3: Instalar v2.0
──────────────────────
1. Copie manutencao_impar_v2.py para: C:\Ímpar\manutencao_impar.py
2. Abra PowerShell (admin)
3. Execute:
   cd C:\Ímpar
   python manutencao_impar.py --init
   python manutencao_impar.py --test


PASSO 4: Agendar no Task Scheduler
───────────────────────────────────
Abra PowerShell (admin) e execute TUDO de uma vez:

$action = New-ScheduledTaskAction -Execute 'python' -Argument 'C:\Ímpar\manutencao_impar.py'
$trigger = New-ScheduledTaskTrigger -AtStartup
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -Action $action -Trigger $trigger -TaskName 'Ímpar_AutomationMonitor' -RunLevel Highest -Settings $settings -Force


PASSO 5: Reiniciar
──────────────────
Restart-Computer -Force

═════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════

❌ "Python não encontrado"
   → Instale Python 3.9+ de https://www.python.org/downloads/
   → Marque "Add Python to PATH"
   → Reinicie PowerShell


❌ "Arquivo não encontrado"
   → Copie manutencao_impar_v2.py para C:\Ímpar\
   → Verifique caminho:
     C:\Ímpar\manutencao_impar.py


❌ "Erro de permissão ao inicializar"
   → Abra PowerShell como ADMINISTRADOR
   → Execute novamente


❌ "Nenhuma mensagem de erro nos logs"
   → NORMAL! v2.0 só loga quando há problema
   → Se há erros, aguarde até 2 horas para reparo automático
   → Ou execute testes: python C:\Ímpar\manutencao_impar.py --test


❌ "Taxa de sucesso baixa (< 85%)"
   → Verificar erros ativos:
     (Get-Content C:\Ímpar\Automações\skill_memory.json -Raw | ConvertFrom-Json).erros_ativos
   → Se houver, aguarde reparo automático
   → Máximo 2 horas de tolerância
